# v0.4.0 — 思源规则提醒

新增从思源 `DSH-REMINDER` callout 维护提醒来源，与 context-care v0.9.0 的共享 `reminderRules` 服务协作，把规则命中的提醒交给会话请求。

- 同一思源内核共享一条只读 WebSocket；断线撤回来源并退避重连，配置更新及最后一个消费者退出时清理连接。
- 内部提醒读取固定执行事务／索引屏障及提醒 SQL，支持按文档局部刷新。插件维护来源所需的订阅和读取与模型工具审批分离；公共 `invoke` 继续按端点授权。
- 保留连接绑定、配置 revision、取消、释放和错误脱敏，屏障失败或配置失效后停止后续查询。
- 发行包携带编译后的 JavaScript 与类型声明，GitHub 标签安装直接使用产物。

安装引用：`github:leolee9086/dsh-plugin-siyuan#v0.4.0`。规则提醒搭配 `github:leolee9086/dsh-context-care#v0.9.0`。

验证：思源全量行为与协议回归 84/84 通过；版本构建和归档入口检查通过。真实思源 callout 样本经来源注册与真实 Worker 收集，首次产生一条提醒，重复收集为零。运行中的插件加载由安装方完成。
